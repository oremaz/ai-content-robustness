\paragraph{Watermark testing and calibration}
A keyed watermark makes generated outputs statistically depend on an owner-controlled secret while preserving their usefulness. Let $\mathcal X$ be the output space, either finite text sequences or RGB images, and let $k\in\mathcal K$ be a key in a specified key space $\mathcal K$. A score function $S:\mathcal K\times\mathcal X\to\mathbb R$ returns $S_k(x)=S(k,x)\in\mathbb R$ for output $x\in\mathcal X$. A threshold $\tau\in\mathbb R$ yields decision $\mathbf1\{S_k(x)>\tau\}\in\{0,1\}$. The null hypothesis is that the output lacks this watermark. A false positive flags such an output; detection rate counts flagged marked outputs.

Some detectors return a scalar $p$-value in $[0,1]$, the null tail probability of an equally or more extreme statistic. At level $\alpha\in(0,1)$, the rule flags $p\leq\alpha$. A valid null model is needed for this rule's false-positive interpretation. AUROC measures ranking over thresholds; it does not determine detection at the chosen operating point.

For a payload of $B\in\mathbb N_{>0}$ bits, let $m,\widehat m\in\{0,1\}^B$ be the embedded and recovered messages. Their number of matching bits is $b=\sum_{j=1}^B\mathbf1\{\widehat m_j=m_j\}\in\{0,\ldots,B\}$, and bit accuracy is $b/B\in[0,1]$. A payload with 70 correct bits out of 100 has 70\% bit accuracy. It contributes one detected output only if it crosses the frozen decision threshold. A binomial null assumes independent balanced bit matches, an assumption that a learned extractor may violate. Calibration therefore uses separate clean examples.

For $n$ independent null outputs with common false-positive probability $f$, let $X$ count false positives. After observing $X=0$, invert the binomial probability at the upper endpoint $f_U$:
\begin{align}
 \Pr_f(X=0)&=(1-f)^n,\label{eq:null-zero-probability}\\
 (1-f_U)^n&=0.05
 \quad\Longrightarrow\quad f_U=1-0.05^{1/n}.
 \label{eq:null-zero-upper-bound}
\end{align} At $n=256$ it is about 1.16\%. A nominal 0.1\% target consequently needs substantially more null evidence. Calibration data and final attack tests have separate roles.
