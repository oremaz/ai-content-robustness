The following appendices retain the detector catalogue, full current watermark tables, historical controls and current fixed-sample galleries. Operational protocols and the remaining historical documents are also included below as separate LaTeX records under \path{tex/records/}; \path{tex/provenance/migration.json} maps each original document to its retained source and records its hash. This avoids repeating setup instructions and obsolete status pointers throughout the scientific narrative.

Typeset examples display unavailable Unicode glyphs using explicit \texttt{[U+XXXX]} markers. Exact original strings remain in the portable examples JSON and the hashed source-document snapshot. Preview figures are resized displays; quantitative image measurements use native outputs. Recorded historical receipts certify their original experiments, not a fresh rerun in the current writing session.
