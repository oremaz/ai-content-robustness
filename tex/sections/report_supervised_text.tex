\subsection{Text detection across datasets}
\label{sec:text_bench}
\paragraph{Question.} Before adapting a generator, the project first asks which supervised detectors transfer beyond their fitting distribution. This subsection requires only the supervised-learning distinction between training, validation and test sets. Its results are independent of the subsequent reinforcement-learning and watermark experiments.

\paragraph{Models and evidence.} The retained MAGE notebook compares four TF-IDF classifiers (logistic regression, random forest, XGBoost and LightGBM) with six QLoRA classifiers: ModernBERT-base, ModernBERT-large, Qwen3.5-4B-Base, Gemma-4-E4B, Nanbeige4.2-3B and LFM2.5-2.6B. Text labels in this notebook are machine $=0$ and human $=1$. The benchmark reports accuracy, macro F1, ROC-AUC and PR-AUC. Macro F1 gives equal weight to the two class-specific F1 values; it is not automatically the F1 of the AI class alone.

\paragraph{Reading the result.} Qwen has the highest observed MAGE and Pile macro F1, while Gemma has the highest peer-review macro F1. A model ranking on one dataset therefore does not define a universal detector ranking. An encoder can be cheaper to use than a decoder classifier, but this experiment does not provide a matched-compute efficiency frontier.

The peer-review evaluation contains 2,000 items: 1,000 human reviews and 200 generated reviews from each of GPT-4o, Gemini-1.5-Pro, Claude-Sonnet-3.5, Llama-3.1-70B and Qwen-2.5-72B. Its text extraction omits metadata fields such as review ratings and identifiers. This reduces an obvious metadata shortcut, but the evaluation changes both domain and generator. It cannot identify a purely temporal generalization effect. The executed MAGE dataset did not expose the additional MAGE-specific OOD splits named in the notebook introduction; those absent split evaluations must not be reported as completed.

\paragraph{Why this matters later.} The defender-comparison workflow selects the strongest retained non-Qwen decoder and the strongest encoder from the MAGE comparison, then warms them against Qwen-generated continuations. Because selection uses the MAGE test ranking, that ranking is a selection statistic for the later study, not a second untouched confirmation. The CNN/DailyMail prompt evaluation remains a distinct experiment with its own split and overlap audit.

\paragraph{Limits.} These are single-run observations without uncertainty intervals. High classifier scores are not calibrated authorship probabilities. Token limits, class order and dataset-specific style can alter apparent performance. Neither these scores nor later evasion results certify the truth of a document's content.
