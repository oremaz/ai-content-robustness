attacks}\label{record-docs-image-weight-attack-quality-md-quality-recorded-for-earlier-model-weight-attacks}

These are the preserved 512-image evaluations from
\texttt{\seqsplit{watermark\_removal/20261026T110140724565Z}}. Quality
was measured with image-to-class-text CLIP alignment: each image was
compared with
\texttt{\seqsplit{a photo of a <requested ImageNet class>}}. Higher is
better. This is neither paired image similarity nor a comprehensive
measure of perceptual quality.

For RAR, every measured attack changes mean class alignment by less than
0.6\% relative to the watermarked baseline. For DC-AE, clean LoRA at
2,500 steps lowers it by 3.18\%, and full training at 2,500 steps by
4.00\%. Partial merging lowers it by 20.7--27.0\%. These percentages
describe the relative change of this CLIP score, not a percentage of
visual quality lost.

The earlier run did not measure LPIPS, SSIM or paired image-image CLIP
cosine. Its class-alignment values cannot be compared numerically with
the image-image CLIP values in the NFPA run. Matched perceptual
measurements would be required for a direct quality-cost comparison.
