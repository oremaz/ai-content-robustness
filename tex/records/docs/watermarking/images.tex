\section{Image watermarking and
removal}\label{record-docs-watermarking-images-md-image-watermarking-and-removal}

Targets are released DistSeal \textbf{RAR-XL} (256 pixels) and
\textbf{UViT-H/DC-AE} (512 pixels). All current conditions have 512
marked test outputs, 512 clean test controls and 256 clean calibration
images. Owner detectors evaluate frozen outputs after attacks.

NFPA is the authors'
\href{https://proceedings.neurips.cc/paper_files/paper/2025/hash/b48405307576689bea14d221ccba73ae-Abstract-Conference.html}{NeurIPS
2025 method}, using an independent SD2.1 public mirror. The original
SD2.1 host returned 404; byte-for-byte equality with that unavailable
host is not claimed. This is output purification using preserved PNGs to
simulate a closed provider, not a live API or modification of the
provider's weights.

All quality metrics use the same 512 reference PNGs, verified
bit-identical across source experiments. High paired distances after a
weight change can reflect a different valid generated sample; they are
not automatically degraded generation quality. Class-text CLIP
complements image similarity.
