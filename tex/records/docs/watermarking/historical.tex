\section{Historical and incomplete watermark
experiments}\label{record-docs-watermarking-historical-md-historical-and-incomplete-watermark-experiments}

These retained runs are separate protocols. They are not pooled with the
current instruct-Qwen and generic clean-training comparisons. Retired
TextSeal 1 and deleted Qwen-Base outputs are excluded entirely.

\subsection{Earlier image merging and single-class clean
fine-tuning}\label{record-docs-watermarking-historical-md-earlier-image-merging-and-single-class-clean-fine-tuning}

The original image run used the released merge implementation and a
clean LoRA pilot on 50 images of class zero. The later primary
weight-removal run uses an explicitly separated 8,000-image, 800-class
fitting protocol. Different recipes can give different results even for
similarly named attacks.
