Text tables derive exact 95\% Clopper-Pearson binomial intervals from
the saved counts. Image binomial intervals are those in the original
owner evaluation. Jina and matched image-quality mean intervals are
paired-example bootstrap intervals from the saved analyses (2,000
resamples). Intervals describe these fixed data, not a guarantee across
new domains, languages or generators.

The text watermark thresholds differ: TextSeal 2 uses a Gamma p-value
test, whereas the student uses a learned extractor score with thresholds
fitted on disjoint validation outputs. A nominal or target FPR label is
not an observed false-positive rate. Primary and secondary thresholds
are both shown.

Image weight changes can generate another valid sample even for the same
class and seed. Paired metrics therefore measure sample drift and must
be considered alongside class alignment. NFPA modifies a particular
input image, so its access and preservation setting differs. Neither
setting has a universal quality floor or human-verified preservation
pass rate in this repository.

Qualitative examples use eight fixed positions, not best-performing
outputs. Their owner decisions and failure cases remain visible. Image
grids use lossless display encoding after uniform resizing; quantitative
metrics always use native images. Text figures are labeled previews,
with full verbatim responses and questions on the linked pages. Public
snapshots omit watermark secrets, payloads, checkpoints and
machine-specific paths.
