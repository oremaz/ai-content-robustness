\section{Text watermarking and
removal}\label{record-docs-watermarking-text-md-text-watermarking-and-removal}

Target: \textbf{Qwen/Qwen3.5-4B instruct}. BIRA and ordinary rewriting
use \textbf{Llama-3.1-8B-Instruct}. Every current test arm has 256
responses. TextSeal 1 and deleted Qwen-Base experiments are excluded.

TextSeal 2 changes the sampler. The DistSeal-inspired text adaptation
learns a hidden-state teacher and distils it into merged student
weights; this is not an official DistSeal text implementation.

\subsection{Access and
interpretation}\label{record-docs-watermarking-text-md-access-and-interpretation}

BIRA and ordinary paraphrasing receive text only. Direct resampling and
smoothing receive simulated top-10 model probabilities. For TextSeal 2
these are \textbf{pre-watermark underlying logits}: results do not
establish bypass when an API exposes only its keyed sampling
distribution. For the student they come from the merged watermarked
model. Smoothing uses an independent Qwen3.5-0.8B instruct reference.

Direct resampling and smoothing generate fresh answers to the same
question; their similarity to an earlier answer is not an entailment
requirement. Jina cosine is continuous similarity, not a preservation
percentage. NLI is reported only for rewrites, using entailment in both
directions.
