\begin{abstract}
This report studies how AI-content detectors generalize, how generators learn to evade them, and how text and image watermarks survive removal attempts. Short method explanations introduce the mathematics needed to interpret each experiment. The latest results cover a fresh 128-question TextSeal 2 comparison, a support-pruning pilot, a 4,096-prefix false-positive audit, and the post-hoc reanalysis of image preservation.
\end{abstract}
